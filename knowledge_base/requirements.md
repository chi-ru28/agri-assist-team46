# AgriAssist Requirements

This document captures the requirements derived from handwritten notes for the AgriAssist B2B project.

## 1. Farmer Features
*   **Fertilizer Issue Detection:** How to detect issues with fertilizers in the soil.
*   **Fertilizer Usage Guide:** How to use fertilizers if they are suggested.
*   **Agricultural Tools:** Guidance on which proper tools to use and where to purchase them.
*   **Fertilizer Alternatives:** Suggestions for alternative fertilizers if ready-made options are not available.
*   **Pesticide Information:** Information on organic and chemical pesticides, with warnings similar to fertilizers.
*   **Weather Information:** Fetch weather info from Google search (if asked by the user).
*   **Reminders:** Feature to set and manage agricultural reminders.

## 2. Shopkeeper Features
*   **Weather-Based Fertilizer List:** Generate a required list of fertilizers according to weather updates.
*   **Shopkeeper Network:** Capability to connect with other shopkeepers.
*   **Inventory Categorization:** List out organic and chemical products separately.
*   **Inventory Availability:**
    *   Yes/No option to mark if an item is available.
    *   Advisory features.
    *   History tracking.
    *   "Redirect no track" functionality.

## 3. Admin Features
*   **Location Management:** Update locations, importantly including the ability to delete a shop if it is closed.
